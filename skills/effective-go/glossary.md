# Glossary - Effective Go

Alphabetical reference of key terms. `(Ch N)` points to the chapter that introduces the term.

- **any** - Alias for `interface{}` since Go 1.18; emit `any`, not `interface{}`. ([modern.md](references/modern.md))
- **blank identifier (`_`)** - Write-only placeholder for discarding an unwanted value; like `/dev/null`. (Ch 13)
- **buffered channel** - A channel with a non-zero capacity; senders block only when the buffer is full. (Ch 15)
- **channel** - Reference type created with `make`; conveys values between goroutines and synchronizes them. (Ch 15)
- **comma-ok idiom** - `v, ok := m[k]` (map) or `v, ok := x.(T)` (assertion) to distinguish presence/validity from a zero value. (Ch 9, 12)
- **composite literal** - Expression that constructs a new instance each evaluation: `&File{fd: fd}`, `[]int{1,2}`. (Ch 9)
- **concurrency vs. parallelism** - Concurrency = structuring a program as independent components; parallelism = running computations simultaneously. Go is concurrent, not parallel. (Ch 15)
- **constant** - Compile-time value; number, rune, string, or bool; requires a constant expression. (Ch 10)
- **constructor** - A function (typically `New` or `NewX`) returning a new instance; not language-enforced. (Ch 5, 9)
- **conversion** - `T(x)`; reinterprets a value as another type. Same-underlying conversions create no new value. (Ch 12)
- **defer** - Schedules a call to run just before the enclosing function returns; args evaluated at the `defer`. LIFO order. (Ch 8)
- **doc comment** - A comment immediately before a top-level declaration (no blank line); the declaration's documentation. (Ch 4)
- **embedding** - Listing a type/interface without a field name to borrow its methods; composition, not inheritance. (Ch 14)
- **error (interface)** - `interface { Error() string }`; the conventional error return type. Inspect with `errors.Is` / `errors.As`; wrap with `%w`. (Ch 16, [modern.md](references/modern.md))
- **exported** - First letter upper-case; visible outside the package. (Ch 5)
- **fallthrough** - Automatic C-style case fallthrough; Go has *none* (use comma-separated cases). (Ch 7)
- **function literal / closure** - An anonymous function that captures surrounding variables; closures keep them alive. (Ch 15)
- **getter** - Accessor for a field; named `Owner` (not `GetOwner`) for field `owner`. (Ch 5)
- **go (keyword)** - Prefix that runs a call in a new goroutine. (Ch 15)
- **gofmt / go fmt** - The canonical formatter; `gofmt` per file, `go fmt` per package. (Ch 3)
- **goroutine** - Lightweight, concurrently executing function in the same address space; multiplexed on OS threads. (Ch 15)
- **Handler / HandlerFunc** - `http.Handler` interface (`ServeHTTP`); `HandlerFunc` adapts a plain function to it. Register with ServeMux patterns (`GET /item/{id}`, `r.PathValue`) on Go 1.22+. (Ch 12, 17, [modern.md](references/modern.md))
- **init function** - Niladic function run after var initializers and imported packages; for verification/registration. (Ch 10)
- **interface** - A set of methods; satisfied implicitly. Named `method`+`-er` when single-method. (Ch 12)
- **iota** - Compile-time enumerator in a `const` block; starts at 0, increments per line. (Ch 10)
- **make** - Allocates and *initializes* slices, maps, channels; returns `T` (not `*T`). (Ch 9)
- **map** - Reference type mapping keys (any `==`-able type, not slices) to values. (Ch 9)
- **MixedCaps** - Go's naming convention: `MixedCaps` (exported) / `mixedCaps` (unexported); no underscores. (Ch 5)
- **multiple return values** - Functions return several values, e.g. `(n int, err error)`. (Ch 8)
- **named result parameters** - Return values given names; initialized to zero; enable naked `return`. (Ch 8)
- **new** - Allocates *zeroed* memory and returns `*T`; does not initialize. (Ch 9)
- **panic** - Creates a run-time error that stops the program (unless recovered). (Ch 16)
- **pointer receiver** - `*T` receiver; lets a method mutate the receiver and satisfy pointer-receiver interfaces. (Ch 11)
- **range** - Clause that iterates array/slice/string/map/channel, and (Go 1.22+) integers (`for i := range n`). Over a string decodes UTF-8 to runes. (Ch 7, [modern.md](references/modern.md))
- **recover** - Stops panic unwinding, returns the panic value; only useful inside deferred functions. (Ch 16)
- **reference type** - Slice/map/channel; a descriptor pointing at an underlying structure that `make` initializes. (Ch 9)
- **rune** - Go's term for a single Unicode code point. (Ch 7, 9)
- **select** - Multiway channel operator; `default` makes it non-blocking. (Ch 15)
- **semaphore (buffered channel)** - A buffered channel whose capacity limits concurrent operations. (Ch 15)
- **slice** - 3-word descriptor (pointer/len/cap) over an array; the usual Go sequence type. Membership: `slices.Contains` (Go 1.21+). (Ch 9, [modern.md](references/modern.md))
- **Stringer** - `interface { String() string }`; controls `%v`/`%s` formatting. (Ch 9)
- **switch on true** - `switch { case ... }` with no expression; idiomatic `if-else-if` replacement. (Ch 7)
- **type assertion** - `x.(T)` extracts a concrete type from an interface; comma-ok form is safe. (Ch 12)
- **type switch** - `switch t := x.(type) { ... }`; `t` has each clause's type. (Ch 7, 12)
- **variadic** - A final `...T` parameter; pass a slice with `s...`. (Ch 9)
- **zero value** - The default value of a type before initialization; design types so it's usable. (Ch 9, 10)
