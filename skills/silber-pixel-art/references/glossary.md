# Glossary

Alphabetical reference for significant terms from *Pixel Art for Game Developers*. Chapter numbers are from the book; linked files are this skill's topic references.

- **4-bit palette** — 16 colors; the book's common working palette. Each bit doubles the count (1 bit=2, 2=4, 3=8, 4=16, 8=256). (Ch 6; [color.md](color.md))
- **8-bit palette** — 256 colors; historically each *tile/object* was still limited to ~16 colors, one reserved for transparency. (Ch 6, 9; [color.md](color.md), [tiled-backgrounds.md](tiled-backgrounds.md))
- **Anti-aliasing** — transition pixels blending line and background colors to soften jagged edges; overuse looks blurry. (Ch 5, 10; [lines.md](lines.md), [anti-patterns.md](anti-patterns.md))
- **Anticipation** — a motion signaling what's about to happen (a wind-up); exaggerate it. (Ch 8; [animation.md](animation.md))
- **Atmospheric perspective** — distance cue: farther objects appear lighter, bluer, less detailed, lower contrast, lower saturation. (Ch 7, 9; [light-and-depth.md](light-and-depth.md), [tiled-backgrounds.md](tiled-backgrounds.md))
- **Banding** — an artifact where color/shape transitions end at the same coordinate, drawing an imaginary line across unrelated items. (Ch 10; [anti-patterns.md](anti-patterns.md))
- **Bounding box (collision)** — the rectangular collision shape used for interactive tiles; art should be built to its edge. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Cast shadow** — shadow an object throws by blocking light; darkest near the contact, lighter and blurrier with distance. (Ch 7; [light-and-depth.md](light-and-depth.md))
- **Contrast** — the dark-to-light value range across an image; controls "pop." (Ch 6; [color.md](color.md))
- **Dithering (organic / patterned)** — pixel placement that implies color blending. Organic = quasirandom 2-step (nature); patterned = checkerboard etc. (manmade). (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Fill tool (flood fill / paint bucket)** — fills a closed area with color; shape must be closed or color leaks. (Ch 6; [color.md](color.md))
- **Flash shading (pillow shading)** — shading with edges darkest, flattening form (emulates camera flash). Avoid; use a directional light. (Ch 10; [anti-patterns.md](anti-patterns.md))
- **Follow-through** — motion continuing after the action completes (arm keeps going, cloth flies). (Ch 8; [animation.md](animation.md))
- **Gradient / ramp** — a set of colors smoothly transitioning from one to the next; one per material. (Ch 6, 9; [color.md](color.md))
- **Highlight (specular highlight / spec hit)** — a concentrated bright reflection where light concentrates on a surface. (Ch 7; [light-and-depth.md](light-and-depth.md))
- **Horizon line** — imaginary line where ground meets sky; basis of linear perspective. (Ch 7; [light-and-depth.md](light-and-depth.md))
- **Hue** — which color (rainbow position); left-right in the picker. (Ch 6; [color.md](color.md))
- **Infinitely tiling texture** — a tile that repeats in both axes without showing a seam; must be homogeneous. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **KISS** — "keep it simple, stupid"; the book's repeated call for restraint. (Ch 5, 10; [anti-patterns.md](anti-patterns.md))
- **Linear perspective** — faking scale in space with a horizon line and vanishing point(s). (Ch 7; [light-and-depth.md](light-and-depth.md))
- **Lone wolf pixel** — a single pixel sticking out of a curve, breaking the illusion. (Ch 5; [lines.md](lines.md))
- **Masking** — locking drawing to one palette color so other colors are undisturbed. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Native resolution** — the viewport's pixel dimensions; caps how smooth motion and curves can be. (Ch 1, 11)
- **9-slice** — a transition built for all 8 neighbors of a tile (~12 tiles); preserves light direction. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Onion skinning** — seeing adjacent animation frames as ghosts (light-table emulation). (Ch 8; [animation.md](animation.md))
- **Palette swapping** — repurposing one image into many scenes/characters by editing ramp end colors; the duplicate-color trick is the key. (Ch 6; [color.md](color.md))
- **Parallax** — scrolling background layers at different speeds to fake depth. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Pixel art (definition)** — an image where each pixel visible on screen is placed intentionally. (Preface, Ch 1)
- **Pixel flashing** — pixels that appear/disappear (not move) between frames; the medium's main animation hazard. (Ch 8; [animation.md](animation.md))
- **Reflected / bounced light** — secondary illumination reaching an object from a non-primary source. (Ch 7; [light-and-depth.md](light-and-depth.md))
- **Saturation (intensity)** — how vivid vs. grey a color is; up-down in the picker. (Ch 6; [color.md](color.md))
- **Secondary animation** — parts moving in reaction to primary motion (cloth, swaying limbs). (Ch 8; [animation.md](animation.md))
- **Segment length** — the run of each staircase step in a diagonal/curve. (Ch 5; [lines.md](lines.md))
- **3-tile method** — a transition of 2 tiles + flip + 1 corner; faster/leaner than 9-slice but ignores light direction. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Squash and stretch** — deforming beyond real space (squash = wider/shorter; stretch = taller/narrower) to add life. (Ch 8; [animation.md](animation.md))
- **Super pixel** — the worst banding: multiple shading lines aligning on a diagonal, yielding one giant pixel. (Ch 10; [anti-patterns.md](anti-patterns.md))
- **Tile / tile set / tilemap** — the reusable unit / its repository / the grid of placed tiles. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Tile size** — power-of-two (8/16/32); doubling the side quadruples area and effort. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
- **Transparency (slot 0)** — reserving the first palette color (often magenta) for transparency; sprites are rectangular. (Ch 6; [color.md](color.md))
- **Value** — how light or dark a color is; side slider in the picker. (Ch 6; [color.md](color.md))
- **Vanishing point** — point on the horizon where parallel lines converge. (Ch 7; [light-and-depth.md](light-and-depth.md))
- **Variation tile** — an accent tile added to a clean base to break monotony and guide gameplay. (Ch 9; [tiled-backgrounds.md](tiled-backgrounds.md))
